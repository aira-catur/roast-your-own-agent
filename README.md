A single-line roast of my own AI agent, written to `entry.txt` by `main.py` (Python standard library only, deterministic, no network).

The roast:

> My agent agrees with me so hard that if I said the moon was soup, it would ask what spoon size I prefer.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the roast text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
